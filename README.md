## :information_source: About

📈 The start of an admin dashboard built with Next.js and Chakra UI. So far it has the sign-in page, with a custom dark theme and a reusable form `Input` component.

Built in 2022 to study Next.js with Chakra UI and design-system-driven components.

## :arrow_forward: Run

You need [Node.js](https://nodejs.org/) and [Yarn](https://yarnpkg.com/). In the project folder:

```bash
# Install dependencies
yarn

# Start the development server
yarn dev
```

> The app opens at <http://localhost:3000>.
